# IPL Sports Performance Analytics Dashboard

An interactive cricket analytics project built using **Microsoft Power BI** to explore IPL team performance, match outcomes, and toss-related trends through data visualization.

## Project Overview

This project analyzes IPL data through three dashboard pages, presenting tournament-level insights and comparisons in an interactive visual format.

## Dashboard Pages

### 1. IPL Overview & Team Performance

Explores overall tournament statistics and compares team performance.

### 2. IPL Match Analysis

Examines match-level trends and outcomes using interactive visualizations.

### 3. IPL Toss & Match Analysis

Explores toss decisions and their relationship with match outcomes.

## Tools Used

* Microsoft Power BI
* Power Query for data preparation, if used
* DAX for measures and calculations, if used

## Project Files

* Power BI dashboard (`.pbix`)
* PowerPoint presentation (`.pptx`)
* Dashboard screenshots

## How to View the Project

1. Download the `.pbix` file from this repository.
2. Open it using Microsoft Power BI Desktop.
3. Explore the dashboard pages and interactive filters.

## Project Objective

To use data visualization and analysis to identify patterns in IPL team performance, match outcomes, and toss decisions.
